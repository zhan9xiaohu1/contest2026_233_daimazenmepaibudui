# 智爱守护——基于OpenVeLA的多模态非接触式AI居家看护终端

## 一、作品简介
面向独居及高龄老人，依托Gemini-S1(R528)运行OpenVeLA原生系统打造的智能居家安全看护终端。通过外接USB摄像头与板载音频单元实现端侧跌倒视觉检测与异常声纹分类，并联动大屏和米家生态，解决老人突发意外无反馈的居家痛点。
